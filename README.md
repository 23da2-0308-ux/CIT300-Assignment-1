### System Overview
This Java console application manages university student records and models campus locations using fundamental data structures[cite: 1]:
1. **Linked List**: Used to store and display student records dynamically[cite: 1].
2. **Stack**: Keeps track of recent system operations and actions (history)[cite: 1].
3. **Queue**: Manages incoming student service requests sequentially (FIFO)[cite: 1].
4. **Binary Search Tree (BST) / Sorting**: Displays student records organized in sorted order[cite: 1].
5. **Hash Table**: Supports fast $O(1)$ lookup for student records by ID[cite: 1].
6. **Graph (Adjacency List)**: Models campus locations and routes, including connection management and Breadth-First Search (BFS) traversal[cite: 1].
